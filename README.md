# Victoria Tomova Portfolio

Папката е готова за GitHub Pages и не използва `package.json`.

## Структура

```text
index.html          # начална страница и 3 selected projects
projects.html       # всички останали project cards
scss/style.scss     # стиловете
css/style.css       # генерира се от SCSS
js/index.js         # mobile menu, header и годината във footer
images/             # всички изображения
.vscode/settings.json # настройка за Live Sass Compiler
```

Отвори `index.html` с Live Server. Когато променяш `scss/style.scss`, включи
**Watch Sass** — готовият CSS ще се обновява автоматично в `css/style.css`.
